Controls

Fully remappable in-game — keyboard and gamepad, per player. Defaults for Player 1:

Player 1 — Keyboard

Move — W A S D

Punches — U I O (Light / Medium / Heavy)

Kicks — J K L (Light / Medium / Heavy)

Throw — Space · Dash — Shift · Super — P

Player 2 — Keyboard

Move — arrow keys

Punches — Numpad 4 5 6

Kicks — Numpad 1 2 3

Throw — Numpad 0 · Dash — Numpad Enter · Super — Numpad +

Every fighter also has motion specials — quarter-circle forward, dragon-punch, quarter-circle back — plus a super. Check the in-game move list for your fighter.

Online play

Create a room, share the code or invite link, fight. Direct WebRTC P2P when it connects, WebSocket relay when it doesn't — with live ping and connection quality shown in the lobby.

Rollback netcode

Deterministic simulation with rollback on prediction misses, so matches stay responsive on rough connections.

Rooms & invites

Short room codes, ?join=CODE links, direct ?p2p= invites, and QR codes in the lobby.

Regions

North America, Europe, Asia, South America, Oceania — auto-detected, changeable in the lobby.

Lobby chat

Persistent global lobby chat, synced with the server. Player names are sanitised.

Run it yourself

npm install  ·  npm run dev — game + lobby server on port 3000

npm run build — production build  ·  npm run lint — type-check

Stack: React 19 · TypeScript · Vite 8 · Tailwind CSS 4 · Express + WebSocket lobby server · Vercel hosting.

Full setup, environment variables, and project structure are in the README.
