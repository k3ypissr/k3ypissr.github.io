What is included

Inside the panel

Two surviving HackBar lineages, merged into one source-tagged tree — P for HackBar v2.9 (3,440 items), M for the Mod (420 items).

Payload menus

SQL, WAF, UNION, LFI, XSS, encoding and tool menus — 3,652 entries across 177 menus, each tagged with its source.

Load & split URL

Load the current request into the panel, split it into parameters, edit, and execute — with POST bodies and custom headers.

Header replay

Custom Referer and Cookie headers. Firefox replaces them for real; Chromium applies them as session rules.

Response viewer

Replayed responses open in a sandboxed viewer with the full header table — no redirect surprises.

Decoder toolkit

Local encoder / decoder and hash helpers, right in the panel. Nothing leaves your browser.

Admin Finder

Wordlist scanner for admin panels, plus Reverse IP lookup and a network viewer for what the browser actually saw.

Two minutes

Install

Chrome 116+

  1. Download the .zip from the release above and unzip it.
  2. Open chrome://extensions and turn on Developer mode.
  3. Click Load unpacked and pick the folder.
  4. Press F9 on any page to toggle the panel.

Firefox 115+

  1. Download the .xpi from the release above.
  2. Open about:debugging#/runtime/this-firefox, click Load Temporary Add-on, and pick the file — or install the signed .xpi.
  3. Press F9 on any page to toggle the panel.

Legacy · XUL

The rebuilt XUL add-on is for Firefox 1.5–6.0 only. It does not install on modern Firefox — it is kept in the Firefox repo under legacy/ and in the v3.0.0 release for history and old setups, with the full Pro menus, the Mod SQL / admin / VM modules, and the original how-to guide.
