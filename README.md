## How it works

Plain HTML, CSS and JavaScript — no build step, no framework. GitHub Pages serves the `main` branch, so pushing to `main` is deploying.

## The projects

- **KBMK** — *Kotha Bolo Mon Khule.* Real-time, on-screen translation for Windows. Type in one language, read it in another — in any app. [Repository](https://github.com/k3ypissr/KBMK)
- **Fatal Circuit: Street Crown** — 16-bit Neo-Geo 1v1 fighting game. Rollback netcode, WebRTC lobbies, 8 fighters, 6 modes. [Repository](https://github.com/k3ypissr/Fatal-Circuit) · [Play](https://fatal-circuit.vercel.app/)
- **K3ypissr NukeBar** — The classic HackBar rebuilt for Chrome and Firefox (Manifest V3). 3,652 payloads across 177 menus, header replay, decoder, Admin Finder and Reverse IP — plus the legacy XUL build for Firefox 1.5–6.0. [Chrome](https://github.com/k3ypissr/nukebar-chrome) · [Firefox](https://github.com/k3ypissr/nukebar-firefox) · [Landing page](https://k3ypissr.github.io/Nukebar/)
